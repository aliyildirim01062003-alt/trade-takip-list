# 📈 Ticaret Takip Listesi

Ücretsiz ticaret günlüğü ve analiz uygulaması

## 🌟 Özellikler

- ✅ **İşlem Kaydı** - Hisse, Kripto, Forex, Emtia vb. işlemleri kaydedin
- 📊 **Detaylı İstatistikler** - Kar/zarar, kazanç oranı, kar faktörü gibi metrikleri görün
- 📈 **Interaktif Grafikler** - Kümülatif kar/zarar, varlık dağılımı ve daha fazlasını görselleştirin
- 💾 **Yerel Depolama** - Verileriniz tarayıcınızda güvenli şekilde saklanır
- 🎨 **Modern Tasarım** - Responsive ve kullanıcı dostu arayüz
- 🚀 **Hızlı ve Hafif** - Ağır bağımlılıklar olmadan işlem yapar

## 📋 İşlem Özellikleri

### Yeni İşlem Ekle
- Tarih, varlık türü, sembol/kod belirleyin
- Alış/Satış işlem türü seçin
- Giriş ve çıkış fiyatlarını girin
- Miktar ve komisyon bilgilerini ekleyin
- İşlem hakkında notlar yazın

### İşlem Yönetimi
- İşlemleri listele ve filtrele
- Varlık türüne göre filtrele
- Tarihe veya kar/zarar'a göre sırala
- İşlemleri düzenle veya sil
- Her işlemin kar/zarar durumunu görün

## 📊 İstatistikler

Sağlanan metrikler:
- Toplam işlem sayısı
- Kazanan ve kaybeden işlem sayısı
- Kazanç oranı (%)
- Toplam kar/zarar
- Ortalama kar ve zarar
- Kar faktörü (Profit Factor)

## 📈 Grafikler

- **Varlık Dağılımı** - Türe göre işlem sayısı
- **Kazanan vs Kaybeden** - İşlem başarı oranı
- **Kümülatif Trend** - Zamana göre kar/zarar eğilimi

## 🚀 Kullanmaya Başlayın

### Gereksinimler
- Node.js (v14+)
- npm veya yarn

### Kurulum

```bash
# Repository'yi klonlayın
git clone https://github.com/aliyildirim01062003-alt/trade-takip-list.git
cd trade-takip-list

# Bağımlılıkları yükleyin
npm install

# Uygulamayı başlatın
npm start
```

Uygulama `http://localhost:3000` adresinde açılacaktır.

## 📦 Teknoloji Stack

- **React 18** - UI Framework
- **Chart.js** - Grafikler
- **CSS3** - Styling
- **LocalStorage API** - Veri saklama

## 💡 Kullanım İpuçları

1. **Düzenli Kayıt** - Her işlemi hemen sonrasında kaydedin
2. **Notlar Ekleyin** - İşlem hakkında strateji veya düşüncelerinizi yazın
3. **İstatistikleri Takip Edin** - Düzenli olarak performansınızı analiz edin
4. **Grafiklerden Yararlanın** - Trendleri görmek için grafikleri inceleyin
